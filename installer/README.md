# installer/ — как собрать то, что раздаётся

```bash
env\Scripts\python.exe build.py
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" installer\vahta.iss
```

`winget` ставит Inno Setup **на пользователя**, в `%LOCALAPPDATA%\Programs`,
а не в `Program Files (x86)` — искать его там значит не найти.

Первая команда кладёт `dist\Вахта\` (onedir: exe и `_internal` рядом) и пишет
`version.iss`. Вторая собирает `dist\Vahta-Setup-<версия>.exe`.

Inno Setup нужен версии **6.3 или новее** (`ArchitecturesAllowed=x64compatible`
и `DownloadTemporaryFile` появились раньше, но именно в такой связке проверено
на 6.3). Ставится один раз:

```bash
winget install JRSoftware.InnoSetup
```

## Раздать собранное

Инсталлер выкладывается в релиз на GitHub с тегом `v<версия>`:

```bash
gh release create v0.6.0 dist/Vahta-Setup-0.6.0.exe --title "Вахта 0.6.0" --notes "…"
```

Хэш считать руками не нужно: GitHub сам считает SHA-256 каждого файла релиза,
и «Вахта» сверяет закачку именно с ним (`vahta/releases.py`). Релиз не должен
быть черновиком или пререлизом — такие автообновление не видит.

## Решения, которые видны только здесь

**Ставим на пользователя,** в `%LOCALAPPDATA%\Programs\Vahta`. Не в
`Program Files`: «Вахта» держит данные в папке `data` рядом с exe, а туда
писать нельзя без прав администратора — и тогда `paths.data_dir()` увёл бы их
в профиль, то есть в другое место у каждого. Заодно установка не спрашивает UAC.

**Установка поверх — это обновление, а не установка рядом.** Тот же `AppId`
(он объявлен один раз через `#define` и используется и в `[Setup]`, и в коде,
который читает ключ деинсталляции), та же папка, прежние галочки
(`UsePreviousAppDir`, `UsePreviousTasks`), данные на месте. На странице «Готово
к установке» видно, с какой версии на какую, — чтобы это было видно, а не
предполагалось.

**Данные при обновлении не трогаются.** Инсталлер удаляет только то, что клал
сам; папку `data` создаёт приложение, и в `[Files]` её нет — она вдобавок
исключена явно (`Excludes`), потому что достаточно один раз запустить собранную
«Вахту» из `dist`, чтобы рядом с exe появилась папка с чужим входом в Twitch,
и она молча уехала бы в инсталлер.

**`_internal` прошлой версии стирается перед копированием** (`[InstallDelete]`).
PyInstaller меняет состав этой папки от сборки к сборке: `ignoreversion`
перезапишет то, что кладёт сам, а лишний `.pyd` от старой версии остался бы
лежать и однажды был бы подхвачен вместо нового. `data` это не касается — она
рядом, а не внутри.

**Запущенную «Вахту» инсталлер закрывает сам.** В `InitializeSetup` он запускает
её же exe с ключом `--quit`: тот стучится в `/api/quit`, и «Вахта» выходит тем же
путём, что по «Выходу» в трее — останавливает фарм, закрывает базу, запоминает
окно. Про порт и HTTP знает exe, инсталлеру это ни к чему. Работала до
обновления — поднимаем обратно молча (`Check: WasRunning`), потому что выключили
её мы, а не человек.

Не вышло — сработает `AppMutex`, и инсталлер попросит закрыть руками, как
раньше. **Ровно так и будет при обновлении с 0.1.0:** та сборка ключа `--quit`
не знает и на него просто откроет своё окно. Начиная с 0.2.0 обновление идёт
без вопросов.

**О данных спрашивают один раз — при удалении.** Там вход в Twitch, история
фарма: молча удалить нельзя, молча оставить —
значит насорить в системе. По умолчанию «нет».

**Ключ автозапуска пишется ровно в том виде, в каком его ставит сама «Вахта»**
(`vahta/autostart.py`): `HKCU\...\Run`, значение `Vahta`, команда
`"путь\Вахта.exe" --autostart`. Иначе переключатель в настройках не увидел бы
галочку из инсталлера. Снимается и при удалении, даже если ключ ставил не
инсталлер, а приложение.

**`AppMutex` остался запасным путём,** имя то же, что в `vahta/single.py`.
«Вахта» живёт в трее и держит свои файлы открытыми; без этой проверки установка
поверх упёрлась бы в занятый exe.

**Фигурные скобки внутри комментария Pascal Script закрывают комментарий.**
Строчка «путь берём не из `{app}`» в комментарии `{ ... }` сломала компиляцию
на «Identifier expected» — `{app}` закрыл комментарий, и остаток строки стал
кодом. В комментариях о константах Inno — только словами.

**WebView2 скачивается на месте, а не лежит внутри.** Рантайм предустановлен
на всех Windows 11 и на Windows 10 с обновления 2018 года — бутстраппер нужен
единицам, обновляется сам по себе и весит полтора мегабайта. Нет интернета —
установка не падает: без WebView2 интерфейс открывается в браузере, и «Вахта»
об этом знает.

**Подписи нет и не будет.** SmartScreen предупредит при скачивании;
сертификат стоит дороже, чем проект соберёт за год. Об этом сказано на
странице загрузки, а не замаскировано.
