# Движение и наведение

Всё быстрое и без пружин. Две кривые: `cubic-bezier(.2,0,.2,1)` для входа, `linear` для прогресса.
Ничего не двигается дольше 180 мс, кроме прогресс-баров.

## Наведение и нажатие

- **Строка таблицы**: фон → `--panel-active` (тёмная) / `#faf8fc` (светлая), 90 мс. Границы не меняются, строка не «поднимается», ничего не сдвигается.
- **Кнопка вторичная**: граница `--line` → `--accent-line`, текст → `--ink`. Фон не появляется.
- **Кнопка главная**: фон `--accent-bg` светлеет на ~6%, при нажатии темнеет и сдвигается на 1px вниз.
- **Чип фильтра**: как вторичная кнопка. Активный чип не реагирует на наведение.
- **Ссылка «Открыть сайт», «Привязать»**: подчёркивание появляется, цвет не меняется.
- **Пункт меню в трее**: фон `--raised`, без анимации (это системное меню, должно быть мгновенным).
- Фокус с клавиатуры: обводка 1px `--accent` + смещение 2px. Видна всегда, даже при наведении мышью.

## Перетаскивание приоритета (главное взаимодействие)

1. Ручка (2×3 точки) видна всегда серой, при наведении на строку → `--dim`, при наведении на ручку → `--accent`, курсор `grab`.
2. Взяли: строка приподнимается — тень `0 12px 28px rgba(0,0,0,.55)`, фон `#221a33`, граница `--accent-line`, масштаб не меняется. Курсор `grabbing`.
3. Остальные строки становятся `opacity:.72`. На месте, куда упадёт строка, — линия 2px `--accent` с точкой слева и подписью «СТАНЕТ ПЕРВЫМ» / «БУДЕТ 4-Й». Соседи расходятся сдвигом за 120 мс.
4. Номер в поднятой строке показывает переход: `3→1`.
5. Отпустили: строка садится за 140 мс, панель справа сразу пересчитывает «что меняет порядок» (числа перерисовываются без анимации). Порядок сохраняется мгновенно, график пересчитывается только по «Применить».
6. С клавиатуры: `Alt+↑/↓` двигает выбранную строку по одной позиции, `Alt+Home` — наверх. Те же подписи озвучиваются для скринридера.
7. Отмена: `Esc` во время перетаскивания возвращает строку на место, «Отмена» в панели — откатывает уже применённый порядок (одна ступень).

## Прогресс и время

- Прогресс-бар смены: `width` анимируется `linear` 1000 мс на каждое обновление (данные приходят раз в минуту — полоса едет плавно, а не прыгает).
- Часы «03:40» и «ОСТАЛОСЬ 1 Ч 02 М» — просто перерисовка раз в секунду/минуту, без анимации цифр.
- Точка «в эфире» пульсирует: `opacity .55 → 1`, 2 с, `ease-in-out`, бесконечно. Единственная бесконечная анимация в интерфейсе.
- Иконка в трее: средняя полоса перерисовывается при каждом обновлении прогресса (шаг 1/16 длины), без анимации — это системная иконка.

## Появление

- Смена таба: контент появляется без перехода (мгновенно). Никаких слайдов между экранами — это десктоп, не карусель.
- Диалог конфликта: фон затемняется до 55% за 120 мс, окно — `opacity 0→1` + `translateY(6px→0)` за 140 мс.
- Тост «Дроп забран: THE FINALS 3/4» — правый нижний угол над статусной строкой, влетает на 8px, живёт 4 с, уходит по `opacity`. Не перекрывает кнопки.
- «Пересчитать»: кнопка показывает моно-текст «ПЕРЕСЧЁТ…», строки графика не мигают — обновляются на месте. Если пересчёт дольше 400 мс, шапка таблицы получает тонкую бегущую полосу 2px `--accent` (indeterminate, 1.2 с).

## Чего не делать

- Не анимировать высоту таблиц и не делать skeleton-мерцание: данные локальные, приходят мгновенно.
- Не двигать сайдбар и не сворачивать его анимацией.
- Не подсвечивать всю строку акцентом — только фон и левый inset у активной.
- Никаких parallax, blur-подложек, «стекла».
